# Að lesa og reka fyrirtæki

Gagnvirkt námskeið í fjármálalæsi fyrir fólk í rekstri og unglinga sem vilja læra að lesa fyrirtækjasíður og ársreikninga.

Námskeiðið fylgir tilbúnu félagi, Fjöður ehf., í gegnum sjö kafla:

1. Hver er þetta? – kennitala, ÍSAT og rekstrarform
2. Græðir félagið? – rekstrarreikningur, verðlagning og núllpunktur
3. Hver á félagið? – efnahagsreikningur og fjármögnun
4. Hvert fóru peningarnir? – sjóðstreymi og sjóðstýring
5. Myndirðu lána? – kennitölur og mælingar
6. Hvað kostar starfsmaður? – launakostnaður og stjórnun
7. Hvað myndirðu borga? – verðmat

Hver kafli hefur gátu sem opnar næsta kafla og stjórnunaraðstæður án eins rétts svars.

## Keyra

Engin uppsetning eða smíði þarf. Opnaðu `index.html` í vafra.

## Birta á GitHub Pages

1. Settu skrárnar í rót repository.
2. Farðu í **Settings → Pages**.
3. Veldu **Deploy from a branch**, branch `main` og möppu `/ (root)`.
4. Síðan birtist á `https://<notandanafn>.github.io/<repo>/`.

## Uppbygging

```
index.html     Síðan sjálf
css/style.css  Útlit, ljóst og dökkt þema
js/app.js      Gögn, kaflar, gátur og fyrirtækjasíða
```

Efni kaflanna og tölur Fjaðrar eru í `js/app.js` (breyturnar `C`, `D` og `B`).

## Fyrirvari

Kennsluefni, ekki fjármálaráðgjöf. Fjöður ehf. er tilbúið félag.
